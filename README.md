# ☕ Rawalpindi Cafe GIS

### Web-Based Geographic Information System

A WebGIS project designed to explore and visualize cafe locations in Rawalpindi using an interactive web map.

## 📌 About the Project

**Rawalpindi Cafe GIS** is a web mapping project that aims to help users explore cafe locations in Rawalpindi through a simple and interactive map interface.

The project demonstrates how web mapping technologies can be used to display geographic locations and make spatial information easier to understand.

## 🎯 Project Objectives

- Display cafe locations on an interactive map.
- Help users explore geographic locations visually.
- Demonstrate the basic concepts of WebGIS and web mapping.
- Provide a foundation for future GIS-based features.

## 🛠️ Technologies Used

- **HTML** — Webpage structure
- **CSS** — Page styling and layout
- **JavaScript** — Interactive functionality
- **Leaflet.js** — Interactive web mapping
- **OpenStreetMap** — Map tiles and basemap
- **GitHub Pages** — Website hosting

## 🌍 Project Features

- Interactive map interface
- Zoom in and zoom out
- Geographic markers for locations
- Popups displaying location information
- Map layer controls, where configured
